PAINEL SAMARA — ARQUIVOS PRONTOS PARA SUBSTITUIR

Esta versão libera sábados e domingos para agendamento, adiciona 18:00 e inclui o link do Google Maps na mensagem preparada para o WhatsApp. Feriados cadastrados continuam sem atendimento.

COMO APLICAR NO REPOSITÓRIO EXISTENTE
1. Extraia este ZIP.
2. Copie e substitua, mantendo as pastas, os arquivos agenda.html, agenda.css, agenda.js, agenda-server.js e assets/agenda-monograma.svg no repositório do painel.
3. Preserve package.json, arquivos de configuração, variáveis de ambiente e demais arquivos já existentes no repositório.
4. Faça commit e aguarde o deploy do Render terminar.
5. Atualize a página da agenda com Ctrl+F5.

Não execute SQL para estes três ajustes. Os arquivos SQL em supabase/ são incluídos para referência e para uma instalação nova; não os execute novamente no banco já configurado.

A mensagem de WhatsApp é aberta para revisão e envio. Ela inclui endereço salvo nas configurações, link do Google Maps, valor e chave Pix.
